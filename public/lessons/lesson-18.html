🚀 开启 Stage 4：实时 GPU 光栅化管线 (Object-Order Rendering)

为什么线性矩阵能算出非线性的“近大远小”除法 $x / (-z)$？

在 Stage 3（光线追踪）中，我们以像素为外层循环，向场景发射射线（Image-Order）；而在现代 GPU 实时光栅化管线（Stage 4）中，我们把双重循环彻底翻转：**以三角形为外层循环，通过一个 $4 \times 4$ 投影矩阵直接把三维顶点拍扁到二维屏幕上（Object-Order）**！但这里藏着一个看似不可能的数学悖论：根据小孔成像相似三角形，远近缩放必须**除以深度 $-z_e$**（非线性运算），而矩阵乘法永远只能做线性组合 $ax + by + cz + d$！线性矩阵究竟是怎么变出除法来的？

第一步：相似三角形与 4D 齐次坐标 $w_c = -z_e$ 延迟除法诡计

在观察空间（Eye Space，相机在原点朝 $-Z$ 轴看，近平面为 $z_e = -n$，远平面为 $z_e = -f$，且 $0 < n < f$）中，点 $(x_e, y_e, z_e)$ 投影到近平面 $z = -n$ 上的坐标由相似三角形直接给出：

$$x_{\text{proj}} = \frac{n \cdot x_e}{-z_e}, \qquad y_{\text{proj}} = \frac{n \cdot y_e}{-z_e}$$

既然矩阵乘法自身做不了除法，4D 齐次坐标（Homogeneous Coordinates）用了一个绝妙的“分两步走”策略： 矩阵只负责把分母 $-z_e$ 原封不动地搬运到第 4 个分量 $w_c$ 上（只需令矩阵第 4 行为 $[0, 0, -1, 0]$），而把真正的除法留给硬件固定管线最后的 透视除法 (Perspective Divide: $[x_c/w_c,\; y_c/w_c,\; z_c/w_c]$)！

第二步：为什么深度 $z_{\text{ndc}}$ 必然是关于 $1/z_e$ 的双曲线？

为了让三维空间中的直线与平面在透视除法后依然保持为直线与平面（从而支持屏幕空间的线性插值），裁剪空间的 $z_c$ 必须是 $z_e$ 和 $1$ 的线性组合 $z_c = A z_e + B$。除以 $w_c = -z_e$ 后，标准设备坐标（NDC）的深度必然具有如下双曲线形式：

$$z_{\text{ndc}}(z_e) = \frac{z_c}{w_c} = \frac{A z_e + B}{-z_e} = -A - \frac{B}{z_e}$$

代入边界条件：近平面 $z_e = -n \mapsto z_{\text{ndc}} = -1$，远平面 $z_e = -f \mapsto z_{\text{ndc}} = +1$，立刻唯一解出透视投影矩阵 $M_{\text{persp}}$：

$$M_{\text{persp}} = \begin{bmatrix} \frac{2n}{r-l} & 0 & \frac{r+l}{r-l} & 0 \\ 0 & \frac{2n}{t-b} & \frac{t+b}{t-b} & 0 \\ 0 & 0 & -\frac{f+n}{f-n} & -\frac{2fn}{f-n} \\ \mathbf{0} & \mathbf{0} & \mathbf{-1} & \mathbf{0} \end{bmatrix}$$

2. 为什么必须在透视除法前裁剪？——Cohen–Sutherland 四位区域编码快速线段裁剪

为什么硬件必须在 4D 齐次空间 ($-w_c \le x_c, y_c, z_c \le +w_c$) 裁剪，而不能先除以 $w_c$？ 因为当一条边跨越相机背后的平面 $z_e = 0$（即 $w_c = 0$）时，相机背后的顶点满足 $w_c < 0$！如果冒然先除以负数 $w_c$，正负号会瞬间翻转，导致相机背后的几何体“里外翻转”横穿整个屏幕！

对于线段裁剪，Cohen–Sutherland 算法 (1967) 用极度优雅的 4 位二进制区域码 (Outcode $C = \text{Top}\mid\text{Bottom}\mid\text{Right}\mid\text{Left}$) 实现了零浮点运算的快速筛选：

  • 平凡接受 (Trivial Accept)：若两端点编码按位或 $(C_0 \mid C_1) == 0000_2$，说明两点全在视口内，直接通过！
  • 平凡拒绝 (Trivial Reject)：若两端点编码按位与 $(C_0 \ \& \ C_1) \neq 0000_2$，说明两点处于同一条边界外侧半平面（例如都在右侧或都在上方），连求交都不用算，直接整条丢弃！
  • 跨界求交裁剪：仅当既不平凡接受也不平凡拒绝时，才挑出界外端点，按位检测越界边并求交截断。

💻 4D 齐次空间 Sutherland–Hodgman 裁剪核心实现 (Clipping Against w_c + x_c >= 0)
// 对 4D 齐次裁剪平面 f(v) = v.w + sign * v[axis] >= 0 执行单边 Sutherland-Hodgman 裁剪
std::vector clipPolygonAgainstPlane(const std::vector& poly, int axis, float sign) {
  std::vector out;
  int n = poly.size();
  for (int i = 0; i < n; ++i) {
    const Vec4& S = poly[i];
    const Vec4& E = poly[(i + 1) % n];
    float dS = S.w + sign * S[axis]; // >= 0 表示在视锥半平面内 (Inside)
    float dE = E.w + sign * E[axis];
    bool inS = (dS >= 0.0f), inE = (dE >= 0.0f);

    if (inS && inE) {
      out.push_back(E); // Case 1: In -> In
    } else if (inS && !inE) {
      float t = dS / (dS - dE); // 线性插值求 4D 超平面交点 I
      out.push_back(lerp(S, E, t)); // Case 2: In -> Out
    } else if (!inS && inE) {
      float t = dS / (dS - dE);
      out.push_back(lerp(S, E, t)); // Case 4: Out -> In (先压入交点 I，再压入终点 E)
      out.push_back(E);
    }
  }
  return out;
}
