● Stage 2: 曲线、曲面与 3D 几何表示
🎢 Piecewise Cubic Splines & Curvature Combs • 为什么 C¹ 看起来光滑却依然会闪断乘客的脖子？B-Spline 如何实现全自动 C² 连续？

无缝拼接的艺术：从 Cⁿ/Gⁿ 连续性与曲率梳，到 Catmull-Rom 穿点样条与 B-Spline 滑动窗口

在 Lesson 07 中，一段三次 Bézier 曲线只有 4 个控制点。如果要画一条有 50 个控制点的过山车轨道怎么办？直接用 50 次多项式不仅会剧烈震荡（龙格现象），而且“牵一发而动全身”（无局部控制性）！工程界的标准答案是**分段三次样条 (Piecewise Cubic Splines)**：用每段 4 个点的局部滑动窗口，拼出无限长、局部可控且具备 $C^1$ 或 $C^2$ 光滑度的完美曲线！

Part 1 • 参数连续性 (Cⁿ) vs 几何连续性 (Gⁿ) 与曲率梳物理直觉

为什么两段看起来平滑相接的轨道 (G¹/C¹)，依然会让过山车乘客脖子闪断或让跑车外壳高光折断？

κ(t) = (x'y'' - y'x'') / (x'² + y'²)^(3/2)
C⁰ / G⁰：位置连续 (Position)
S₀(1) = S₁(0) = P₃

两段曲线在接口 $\mathbf{P}_3$ 相连不断裂，但左右切柄 $\mathbf{P}_2\mathbf{P}_3$ 与 $\mathbf{P}_3\mathbf{P}_4$ 折出尖角，速度方向瞬间突变！

G¹：切线方向连续 (Collinear)
P₄ - P₃ = k·(P₃ - P₂), k > 0

$\mathbf{P}_2, \mathbf{P}_3, \mathbf{P}_4$ 三点共线，静态图形完全没有折角！但如果左右手柄一长一短 ($k\neq 1$)，匀速运动经过接口时车速会突然跳变！

C¹：一阶速度连续 (Velocity)
P₄ - P₃ = P₃ - P₂ (k = 1)

左右手柄共线且等长 ($\mathbf{P}_3$ 是 $\mathbf{P}_2\mathbf{P}_4$ 中点)。速度向量平滑过渡，但二阶加速度与曲率梳 $\kappa(t)$ 在接口处依然发生断崖跳变！

C²：二阶加速度连续 (A-Class)
S₀''(1) = S₁''(0)

接口处不仅速度相等，加速度也相等（满足 $\mathbf{P}_1 - 2\mathbf{P}_2 + \mathbf{P}_3 = \mathbf{P}_3 - 2\mathbf{P}_4 + \mathbf{P}_5$）。曲率梳包络线丝滑连续，方向盘零顿挫！

🔬 交互透视镜 1：两段拼接点 ($\mathbf{P}_3$) 的 $C^0 \to G^1 \to C^1 \to C^2$ 连续性与曲率梳 ($\kappa$) 显微镜

点击右侧 4 种连续性锁定模式（或在画布上直接拖拽控制点 $\mathbf{P}_4$），重点观察紫色**曲率梳 (Curvature Comb)** 在接头 $\mathbf{P}_3$ 处是断裂还是连续！

接头 P₃ 两侧物理量跳变遥测 (At Joint P₃):
切线方向夹角 Δθ: 0.0°
速度跳跃 ||S₁'(0) - S₀'(1)||: 0.0
加速度跳跃 ||S₁''(0) - S₀''(1)||: 0.0
Part 2 • MIT 6.837 Lec 03：两大经典样条的 4×4 基矩阵推导

如何摆脱手动调切柄？Catmull-Rom（自动穿点 C¹）vs 均匀三次 B-Spline（全自动 C²）

4-Point Sliding Window [Pᵢ₋₁, Pᵢ, Pᵢ₊₁, Pᵢ₊₂]
1. Catmull-Rom 样条：用邻居连线自动生成切向量 C¹ • 严格穿点

假设给定一串必经航点 $\dots, \mathbf{P}_{i-1}, \mathbf{P}_i, \mathbf{P}_{i+1}, \mathbf{P}_{i+2}, \dots$。为了连接 $\mathbf{P}_i \to \mathbf{P}_{i+1}$ 且无需人工摆弄切线手柄，Catmull 与 Rom 规定：点 $\mathbf{P}_i$ 处的切向量直接取它前后两个邻居连线的一半！

vᵢ = ½(Pᵢ₊₁ - Pᵢ₋₁),    vᵢ₊₁ = ½(Pᵢ₊₂ - Pᵢ)
⇒ 等价 Bézier 内控制点:
B₁ = Pᵢ + (1/6)(Pᵢ₊₁ - Pᵢ₋₁),    B₂ = Pᵢ₊₁ - (1/6)(Pᵢ₊₂ - Pᵢ)
M_CatmullRom = (1/2) · [
   0, -1, 2, -1;
   2, 0, -5, 3;
   0, 1, 4, -3;
   0, 0, -1, 1 ]
2. 均匀三次 B-Spline：放弃穿点，换取完美 C² 与凸包 C² • 1/6:4/6:1/6 加权

为什么 Catmull-Rom 无法做到 $C^2$ 连续？因为强迫曲线穿过每一个点会限制曲率的自由度！如果允许分段接头位于连续三个控制点的 $\frac{1}{6} : \frac{4}{6} : \frac{1}{6}$ 加权质心处，就能解出唯一满足 $C^0+C^1+C^2$ 全连续的 B-Spline 基矩阵：

接头位置 Sᵢ(0) = (1/6)Pᵢ₋₁ + (4/6)Pᵢ + (1/6)Pᵢ₊₁
接头速度 Sᵢ'(0) = ½(Pᵢ₊₁ - Pᵢ₋₁)
接头加速度 Sᵢ''(0) = Pᵢ₋₁ - 2Pᵢ + Pᵢ₊₁ (只与这3个点有关，完美交接!)
M_BSpline = (1/6) · [
   1, -3, 3, -1;
   4, 0, -6, 3;
   1, 3, 3, -3;
   0, 0, 0, 1 ]

🖱️ 拖动任意控制点 P₀..P₆！注意只有相邻的局部曲線段发生变化（局部控制性）！
滑动窗口高亮段 (Segment i): Seg #1 [P₁,P₂,P₃,P₄]

🪟 当前激活的 4 点滑动窗口分析

什么是局部控制性 (Local Control)？ 7 个控制点共生成 4 段三次曲线：第 0 段只读 [P₀,P₁,P₂,P₃]，第 1 段只读 [P₁,P₂,P₃,P₄]……当你拖动 P₀ 时，第 1、2、3 段曲线纹丝不动！

👀 观察画布上两条曲线的核心差异：
  • 琥珀色 Catmull-Rom：老老实实穿过中间每一个控制点 $\mathbf{P}_1..\mathbf{P}_5$，但在急转弯处容易向外“过冲 (Overshoot)”，且接头处曲率会发生跳变。
  • 翠绿色 B-Spline：虽然不穿过控制点（接头位于 $\frac{1}{6}\mathbf{P}_{i-1}+\frac{4}{6}\mathbf{P}_i+\frac{1}{6}\mathbf{P}_{i+1}$），但它的紫色曲率梳包络线如丝绸般顺滑不断裂！
