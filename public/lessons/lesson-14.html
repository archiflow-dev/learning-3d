当光线撞上表面后并未终结：如何仅凭“平行与垂直向量分解”推导出镜面反射与斯涅尔折射？ When a Ray Hits a Surface, Its Journey Just Begins: Deriving Reflection & Snell's Law Purely from Orthogonal Vector Decomposition

在 Lesson 12 和 Lesson 13 的光线投射 (Ray Casting) 中，射线一旦撞上第一个物体就停下来算颜色了——所以画面里既没有阴影，也没有镜子倒影或水晶球折射。1980 年，Turner Whitted 提出了著名的递归光线追踪 (Recursive Ray Tracing)：当主射线撞击表面点 $\mathbf{p}$ 时，点 $\mathbf{p}$ 化身为一个新的“微型相机”，向场景继续发射3 类次级射线 (Secondary Rays)：
① 阴影射线 (Shadow Ray) $\to$ 飞向光源检测是否被遮挡；
② 镜面反射射线 (Reflection Ray $\mathbf{r}$) $\to$ 递归追踪镜面高光倒影；
③ 透射/折射射线 (Refraction Ray $\mathbf{t}$) $\to$ 穿过玻璃、水或钻石内部并发生斯涅尔偏折！

In Ray Casting (Lessons 12–13), rays stop at the first hit. In 1980, Turner Whitted introduced Recursive Ray Tracing: every surface hit point $\mathbf{p}$ acts as a new camera, spawning three types of secondary rays — Shadow Rays toward lights, Reflection Rays ($\mathbf{r}$), and Refraction Rays ($\mathbf{t}$) through dielectrics like glass and water, forming a recursive Ray Tree!

不背三角函数公式！用 Lesson 01 的正交投影分解 $(\mathbf{d}_\parallel + \mathbf{d}_\perp)$ 推导反射与折射向量 Zero Trig Memorization! Deriving Reflection $\mathbf{r}$ and Snell Refraction $\mathbf{t}$ via Orthogonal Decomposition $(\mathbf{d}_\parallel + \mathbf{d}_\perp)$

① 镜面反射向量 $\mathbf{r} = \mathbf{d} - 2(\mathbf{d}\cdot\mathbf{n})\mathbf{n}$：为什么是减去 2 倍？ 1. Mirror Reflection $\mathbf{r} = \mathbf{d} - 2(\mathbf{d}\cdot\mathbf{n})\mathbf{n}$: Why Subtract Twice?

设单位入射射线方向为 $\mathbf{d}$（指向表面，因此与朝外的单位法向量 $\mathbf{n}$ 夹角为钝角，$\mathbf{d}\cdot\mathbf{n} = -\cos\theta_1 < 0$）。 把入射向量 $\mathbf{d}$ 分解为平行于切平面的分量 $\mathbf{d}_\parallel$ 和垂直于表面的法向分量 $\mathbf{d}_\perp$：

$$\mathbf{d}_\perp = (\mathbf{d}\cdot\mathbf{n})\,\mathbf{n}, \qquad \mathbf{d}_\parallel = \mathbf{d} - \mathbf{d}_\perp = \mathbf{d} - (\mathbf{d}\cdot\mathbf{n})\,\mathbf{n}$$

当小球撞击光滑地面反弹时：水平切向速度 $\mathbf{d}_\parallel$ 完全不变，垂直法向速度 $\mathbf{d}_\perp$ 直接反向变成 $-\mathbf{d}_\perp$！因此反射向量 $\mathbf{r}$ 就是：

$$\mathbf{r} = \mathbf{d}_\parallel + (-\mathbf{d}_\perp) = \big(\mathbf{d} - \mathbf{d}_\perp\big) - \mathbf{d}_\perp = \mathbf{d} - 2\mathbf{d}_\perp = \mathbf{d} - 2(\mathbf{d}\cdot\mathbf{n})\,\mathbf{n}$$

几何直觉：减去第 1 个 $(\mathbf{d}\cdot\mathbf{n})\mathbf{n}$ 是把向量压扁拍在切平面上（只剩 $\mathbf{d}_\parallel$）；再减去第 2 个 $(\mathbf{d}\cdot\mathbf{n})\mathbf{n}$ 是把它从切平面向上镜像弹起！

② 斯涅尔折射向量 $\mathbf{t}$ 与全内反射 (TIR)：切向缩放 + 勾股定理 2. Snell Refraction $\mathbf{t}$ & Total Internal Reflection (TIR)

光线从折射率 $\eta_1$ 的介质进入 $\eta_2$ 的介质，服从斯涅尔定律 $\eta_1\sin\theta_1 = \eta_2\sin\theta_2 \implies \sin\theta_2 = \frac{\eta_1}{\eta_2}\sin\theta_1$。
注意看我们的切向分量 $\mathbf{d}_\parallel = \mathbf{d} - (\mathbf{d}\cdot\mathbf{n})\mathbf{n}$：它的长度 $\|\mathbf{d}_\parallel\|$ 正好等于 $\sin\theta_1$！ 所以折射向量的水平切向分量 $\mathbf{t}_\parallel$ 方向与 $\mathbf{d}_\parallel$ 完全相同，长度只需缩放 $\frac{\eta_1}{\eta_2}$ 倍：

$$\mathbf{t}_\parallel = \frac{\eta_1}{\eta_2}\,\mathbf{d}_\parallel = \frac{\eta_1}{\eta_2}\big(\mathbf{d} - (\mathbf{d}\cdot\mathbf{n})\,\mathbf{n}\big)$$

既然总折射向量 $\mathbf{t} = \mathbf{t}_\parallel + \mathbf{t}_\perp$ 是长度为 $1$ 的单位向量，由勾股定理 $\|\mathbf{t}_\parallel\|^2 + \|\mathbf{t}_\perp\|^2 = 1$ 立刻得到朝向界面下方的垂直分量 $\mathbf{t}_\perp$：

$$\mathbf{t}_\perp = -\sqrt{\underbrace{1 - \left(\frac{\eta_1}{\eta_2}\right)^2\big(1 - (\mathbf{d}\cdot\mathbf{n})^2\big)}_{k}}\;\mathbf{n}$$

⚡ 全内反射 (Total Internal Reflection, TIR) 的代数诞生：当光从高折射率玻璃 ($\eta_1=1.5$) 射向低折射率空气 ($\eta_2=1.0$) 时，缩放比 $\frac{\eta_1}{\eta_2} = 1.5 > 1$！一旦入射角超过临界角 $\theta_c = \arcsin(\eta_2/\eta_1) \approx 41.8^\circ$，水平分量长度 $\|\mathbf{t}_\parallel\| = \frac{\eta_1}{\eta_2}\sin\theta_1 > 1$，导致根号下的 $k < 0$！此时折射光线完全消失，$100\%$ 能量转化为全内反射（这正是海底光纤传输激光的原理）！

为什么没有 $\varepsilon$ 偏移会让整个场景布满黑麻子？(Shadow Acne 与 $\mathbf{p} + \varepsilon\mathbf{n}$) Why Zero Bias ($\varepsilon = 0$) Covers Your Scene in Black Measles: Shadow Acne & Normal Offset $\mathbf{p} + \varepsilon\mathbf{n}$

当主射线命中表面点 $\mathbf{p}$ 后，我们要从 $\mathbf{p}$ 向光源方向 $\mathbf{l}$ 发射一条阴影探测射线 $\mathbf{r}_{\text{shadow}}(t) = \mathbf{p} + t\mathbf{l}$。 在理想数学世界里，这条射线与出发表面自身的交点是 $t = 0$（会被 $t > 0$ 过滤掉）。

但在 32 位浮点数 (`float32`) 计算机里，求出来的命中点 $\tilde{\mathbf{p}}$ 有大约 $\pm 10^{-6}$ 的舍入误差——大约有一半的像素点 $\tilde{\mathbf{p}}$ 刚好陷在表面皮下 $10^{-6}$ 处！ 当你从皮下向光源发射射线时，它在 $t \approx +10^{-6} > 0$ 处一头撞上了自己脚下的表面，误以为自己被挡住了！结果向阳面出现一半黑一半亮的摩尔纹黑斑（Shadow Acne 自遮挡伪影）。

$$\mathbf{r}_{\text{shadow}}(t) = (\mathbf{p} + \varepsilon\mathbf{n}) + t\mathbf{l}, \qquad t \in (0, d_{\text{light}})$$

// 1. Mirror Reflection (I and N must be normalized)
vec3 myReflect(vec3 I, vec3 N) {
  return I - 2.0 * dot(N, I) * N;
}

// 2. Snell Refraction with Total Internal Reflection (eta = eta_1 / eta_2)
vec3 myRefract(vec3 I, vec3 N, float eta) {
  float cosI = -dot(N, I);
  float k = 1.0 - eta * eta * (1.0 - cosI * cosI);
  if (k < 0.0) return vec3(0.0); // Total Internal Reflection (TIR)!
  return eta * I + (eta * cosI - sqrt(k)) * N;
}

// 3. Schlick's Fresnel Approximation
float fresnelSchlick(float cosTheta, float eta1, float eta2) {
  float r0 = (eta1 - eta2) / (eta1 + eta2);
  r0 = r0 * r0;
  return r0 + (1.0 - r0) * pow(1.0 - cosTheta, 5.0);
}
