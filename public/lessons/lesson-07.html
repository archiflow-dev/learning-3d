Part 1 • 二项式展开、单位分解与仿射不变性 (连通 Lesson 02 齐次坐标!)

Bernstein 多项式是怎么从 ((1-t) + t)³ = 1 里长出来的？为什么它们的和必须恒等于 1？

Σ Bᵢ³(t) = ((1-t) + t)³ ≡ 1
1. 为什么造型设计首选参数曲线 $\mathbf{P}(t)$？

显式 $y=f(x)$ 无法画垂直线或闭合环；隐式 $F(x,y)=0$ 适合判断点在曲面内外（光追神器），但很难按顺序生成顶点。而参数方程 $\mathbf{P}(t)=(x(t),y(t),z(t))$ 把曲线看作质点在时间 $t\in[0,1]$ 内的运动轨迹，天生支持任意 3D 环路！

2. 二项式定理自然诞生 4 个权重函数

把恒等式 $1 = ((1-t) + t)^3$ 按杨辉三角展开： 1 = (1-t)³ + 3(1-t)²t + 3(1-t)t² + t³ 这四项就是三次 Bernstein 多项式 $B_0^3, B_1^3, B_2^3, B_3^3$！随着 $t$ 从 $0\to 1$，权重像水流一样依次从 $\mathbf{P}_0$ 传向 $\mathbf{P}_1, \mathbf{P}_2, \mathbf{P}_3$。

3. 为什么 $\sum B_i(t) \equiv 1$ 决定了仿射不变性？

回想 Lesson 02：点的齐次坐标 $w=1$！如果你把 4 个控制点平移 $+\mathbf{d}$：$\sum B_i(t)(\mathbf{P}_i + \mathbf{d}) = \mathbf{P}(t) + (\sum B_i(t))\mathbf{d}$。只有当 $\sum B_i(t) \equiv 1$（单位分解）时，平移控制点才等价于平移整条曲线！且因为 $B_i(t)\ge 0$，曲线永远被锁在控制点的凸包 (Convex Hull) 内部！

Part 2 • MIT 6.837 Lec 02 多项式基矩阵大一统：Hermite ↔ Bézier

为什么 P(t) = G · M_basis · [1, t, t², t³]ᵀ 能把一切三次曲线统合成 4×4 矩阵乘法？

P'(0) = 3(P₁ - P₀), P'(1) = 3(P₃ - P₂)
1. 三次 Bézier 基矩阵 M_Bezier 的推导

把四个 Bernstein 多项式按 $1, t, t^2, t^3$ 展开合并同类项：

B₀(t) = 1 - 3t + 3t² - 1t³
B₁(t) = 0 + 3t - 6t² + 3t³
B₂(t) = 0 + 0t + 3t² - 3t³
B₃(t) = 0 + 0t + 0t² + 1t³

系数直接排成一个对称优美的 $4\times 4$ 矩阵 $M_{\text{Bezier}}$！求导立得端点切线速度：P'(0) = 3(P₁ - P₀) 与 P'(1) = 3(P₃ - P₂)！

2. 三次 Hermite 曲线与 Bézier 的双向无损互转

在工程与动画编辑器中，艺术家经常希望直接指定起点 $\mathbf{P}_0$、终点 $\mathbf{P}_3$、起点发射切向量 $\mathbf{v}_0$、终点进入切向量 $\mathbf{v}_1$（这就是 Hermite 曲线）。利用上面的求导公式，二者完全等价：

P₁ = P₀ + (1/3)·v₀   ⇔   v₀ = 3·(P₁ - P₀)
P₂ = P₃ - (1/3)·v₁   ⇔   v₁ = 3·(P₃ - P₂)

这就是为什么你在 Illustrator、Blender 或 Figma 里拖动手柄时，其实是在用 Bézier 控制点 $\mathbf{P}_1, \mathbf{P}_2$ 直观操控 Hermite 切向量 $\mathbf{v}_0, \mathbf{v}_1$ 的 $\frac{1}{3}$！

  • 为什么选择三次多项式 (Cubic, degree 3)？ 一次多项式只是直线；二次多项式（抛物线）没有拐点（Inflection Point，无法画出 S 形）且共面；四次以上多项式容易出现龙格震荡（Runge's Phenomenon）。三次多项式拥有 4 个自由度，刚好能同时独立控制两端位置 $(\mathbf{P}_0, \mathbf{P}_3)$ 与两端切线 $(\mathbf{v}_0, \mathbf{v}_1)$，且能顺滑走出 3D 非平面扭曲与 S 形拐点！
  • 基变换矩阵 $M$ 的统一视角：无论是 Hermite、Bézier，还是下一课要学的 Catmull-Rom 和 B-Spline，都只是更换了同一个 $4\times 4$ 矩阵 $M_{\text{basis}}$！

Prof. Kenneth Joy — Curves in the Plane & de Casteljau Subdivision

📌 Kenneth Joy 教授总结的 Bézier 曲线五大黄金几何性质：
  1. 端点插值性 (Endpoint Interpolation)：曲线必定严格经过首尾控制点 $\mathbf{P}(0) = \mathbf{P}_0$ 与 $\mathbf{P}(1) = \mathbf{P}_3$。
  2. 端点切线性质 (Endpoint Tangent)：起点切向量 $\mathbf{P}'(0) = n(\mathbf{P}_1 - \mathbf{P}_0)$，终点切向量 $\mathbf{P}'(1) = n(\mathbf{P}_n - \mathbf{P}_{n-1})$。
  3. 仿射不变性 (Affine Invariance)：对曲线做任意旋转、缩放、平移或错切，完全等价于只对 4 个控制点做变换后再画曲线（无需对曲线上成千上万个采样点做矩阵乘法！）。
  4. 凸包性质 (Convex Hull Property)：因为 $B_i^n(t) \ge 0$ 且 $\sum B_i^n(t) = 1$，整条曲线 100% 被包裹在控制点的凸包多边形内部，绝不会意外飞出边界。
  5. 变差缩减性质 (Variation Diminishing)：任何直线与 Bézier 曲线的交点个数，绝不会超过该直线与控制多边形折线的交点个数（意味着曲线永远比控制折线更平滑、绝不会无故多出震荡！）。
