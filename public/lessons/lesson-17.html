✨ Stage 3 终章 • James Kajiya (1986) *The Rendering Equation*

为什么 Whitted 光线追踪看起来像“塑料”，而真实世界充满柔和溢色？

在 Lesson 14 的 Whitted-Style 光线追踪中，光线只在完美镜面或玻璃上继续弹射；一旦击中粗糙的漫反射表面（如粉刷墙壁、木桌、织物），算法立刻停止弹射，只向点光源连一条硬阴影射线，再用一个虚假的常数环境光 $k_a I_a$ 强行填亮背光面！但在真实物理世界中：**没有任何物体是光线的终点，每一个受光表面本身都变成了照亮周围物体的“次级面光源”**！

1. 色彩溢色 (Color Bleeding)

康奈尔盒子 (Cornell Box) 顶部的白光打在左侧红墙上，红墙吸收蓝绿光子、向整个半球散射红光子，把旁边纯白球体的背光面染上一层温暖的红晕。

2. 软阴影 (Soft Shadows: Umbra & Penumbra)

真实光源都有面积。地板上某点如果被球体遮挡了面光源的 60%，它仍能接收到其余 40% 光源面积发出的光子，从而自然形成从本影 (Umbra) 到半影 (Penumbra) 的柔滑过渡。

3. 焦散与环境遮蔽 (Caustics & Contact GI)

墙角与球体接触缝隙处之所以深邃，是因为那里的上半球立体角被邻近几何体遮蔽，多跳间接光子难以钻入——无需任何 SSAO 屏幕空间造假，物理积分自然涌现！

1. 辐射度量学与 Kajiya 渲染方程：为什么漫反射 BRDF 等于 $\frac{\rho}{\pi}$ 而不是 $\frac{\rho}{2\pi}$？

为什么光线追踪器沿着射线传输的物理量不是功率 $\Phi$（瓦特），也不是照度 $E = \frac{d\Phi}{dA}$，而是**辐射亮度 (Radiance $L$)**？

$$L(\mathbf{x}, \vec{\omega}) \equiv \frac{d^2 \Phi(\mathbf{x}, \vec{\omega})}{dA_\perp \, d\omega} = \frac{d^2 \Phi(\mathbf{x}, \vec{\omega})}{(dA \cos\theta) \, d\omega} \qquad [\text{W}\cdot\text{sr}^{-1}\cdot\text{m}^{-2}]$$

3Blue1Brown 几何直觉：一束立体角为 $d\omega$ 的光束以倾角 $\theta$ 照在面积为 $dA$ 的斜面上，它真正拦截到的垂直横截面积只有 **$dA_\perp = dA \cos\theta$**（这就是兰伯特余弦定律 $\cos\theta = \mathbf{n} \cdot \vec{\omega}_i$ 的纯粹几何起源！）。更妙的是，在真空中沿着一条光线走，距离 $r$ 翻倍导致的能量密度 $1/r^2$ 衰减，恰好被传感器立体角 $d\omega = dA/r^2$ 的 $1/r^2$ 缩小**完美抵消**——因此 **Radiance $L$ 沿着整条光线是严格守恒的常数**！

1986 年 James Kajiya 写下了统治整个现代离线与实时渲染的 **渲染方程 (The Rendering Equation)**：点 $\mathbf{x}$ 朝出射方向 $\vec{\omega}_o$ 射出的总辐射亮度 $L_o$，等于它自身的发光 $L_e$，加上上半球 $\Omega^+$ 所有入射方向 $\vec{\omega}_i$ 照进来的光经材质 **BRDF（双向反射分布函数 $f_r$）** 散射后的积分：

$$L_o(\mathbf{x}, \vec{\omega}_o) = L_e(\mathbf{x}, \vec{\omega}_o) + \int_{\Omega^+} f_r(\mathbf{x}, \vec{\omega}_i, \vec{\omega}_o) \, L_i(\mathbf{x}, \vec{\omega}_i) \, \underbrace{(\mathbf{n} \cdot \vec{\omega}_i)}_{\cos\theta_i} \, d\omega_i$$

经典灵魂拷问：一个反照率为 $\rho \in [0,1]$ 的理想漫反射面（向所有方向均匀散射相同 Radiance），它的常数 BRDF $f_r$ 为什么等于 $\frac{\rho}{\pi}$，分母为什么是 $\pi$ 而不是半球面积 $2\pi$？

让我们用 **努塞尔类比 (Nusselt's Analog)** 给出最直观的几何证明：立体角微元 $d\omega = \sin\theta\,d\theta\,d\phi$ 是单位半球面上的小面元；而乘上倾斜因子 $\cos\theta$ 后，$d\omega_\perp = \cos\theta \, d\omega$ 恰好等于**把这个球面小面元垂直往下拍扁、正交投影到底部单位圆盘上的面积微元 $dx\,dy$**！ 既然整个单位半球正交投影到底面的影子就是一个半径为 $1$ 的圆盘，它的总投影面积当然是 **$\pi \times 1^2 = \pi$**！

$$\int_{\Omega^+} \cos\theta \, d\omega = \int_0^{2\pi}\! d\phi \int_0^{\pi/2}\! \cos\theta \sin\theta \, d\theta = \mathbf{\pi} \;\;\implies\;\; f_r = \frac{\rho}{\pi}$$

2. 为什么无限弹射的积分不会死循环？——俄罗斯轮盘赌 (Russian Roulette) 无偏终止法

渲染方程是一个递归积分方程（光子可以在红墙、白球、地板之间弹射 $1, 2, 3, \dots, \infty$ 次）。如果我们粗暴地规定“最多弹射 3 次就强制归零截断”，那么第 $4, 5, \dots$ 次弹射携带的真实能量就被永久丢弃了，渲染出的房间会系统性地偏暗（即有偏估计 Biased Estimator）。

怎样才能既在有限步内以 100% 概率停机，又让数学期望严格等于无穷级数真值（100% 无偏 Unbiased）？答案是冯·诺依曼与乌拉姆在曼哈顿计划中发明的 **俄罗斯轮盘赌 (Russian Roulette)**：

$$\hat{L}_{\text{RR}} = \begin{cases} \dfrac{L_{\text{bounce}}}{q}, & \text{以存活概率 } q \in (0, 1] \text{ 继续追踪下一跳（能量补偿放大 } 1/q \text{ 倍！）} \\[8pt] 0, & \text{以终止概率 } 1 - q \text{ 立即停止弹射} \end{cases}$$

看看它的数学期望发生了什么奇迹： $$\mathbb{E}[\hat{L}_{\text{RR}}] = q \cdot \left(\frac{\mathbb{E}[L_{\text{bounce}}]}{q}\right) + (1 - q) \cdot 0 = \mathbb{E}[L_{\text{bounce}}]$$ 概率 $q$ 与分母 $q$ 精确相消！通常我们令存活概率 $q = \min(0.95,\; \max(\beta_R, \beta_G, \beta_B))$（当前路径累积透射率越暗，越容易被淘汰；一旦幸存，就除以 $q$ 补足全村的希望）！

💻 工业级无偏蒙特卡洛路径追踪器核心实现 (含 Malley 余弦采样 + 俄罗斯轮盘赌)
// 1. Malley 圆盘投影法生成余弦加权半球方向 p(ω) = cos(θ) / π
Vec3 sampleCosineHemisphere(const Vec3& normal) {
  float r1 = randomFloat(), r2 = randomFloat();
  float r = sqrt(r1), phi = 2.0f * PI * r2;
  float x = r * cos(phi), y = r * sin(phi);
  float z = sqrt(max(0.0f, 1.0f - r1)); // 垂直投影到单位半球面
  return localToWorld(Vec3(x, y, z), normal);
}

// 2. 迭代式无偏路径追踪 (Iterative Unbiased Path Tracer)
Vec3 tracePath(Ray ray, const Scene& scene) {
  Vec3 L_accum(0, 0, 0);
  Vec3 beta(1, 1, 1); // 路径累积吞吐量 (Path Throughput)

  for (int bounce = 0; bounce < MAX_BOUNCES; ++bounce) {
    HitInfo hit = scene.intersect(ray);
    if (!hit.happened) break;

    // 累加光源自发光项 L_e
    L_accum += beta * hit.material.emission;

    // 俄罗斯轮盘赌 (Russian Roulette)：从第 3 跳起按最大分量概率存活
    if (bounce >= 2) {
      float q = min(0.95f, max({beta.x, beta.y, beta.z}));
      if (randomFloat() > q) break;
      beta /= q; // 幸存路径无偏能量补偿！
    }

    // 余弦重要性采样：f_r * cos(θ) / p(ω) = (albedo / π) * cos(θ) / (cos(θ) / π) = albedo！
    Vec3 wi = sampleCosineHemisphere(hit.normal);
    beta *= hit.material.albedo;
    ray = Ray(hit.pos + hit.normal * EPS, wi);
  }
  return L_accum;
}
