✨ From $O(N)$ Brute-Force to $O(\log N)$ Real-Time Ray Tracing

为什么没有加速结构的光线追踪慢一百万倍？如何用“三明治区间交集”与“几何概率论”拯救渲染时间？ Why Naive Ray Tracing Is a Million Times Too Slow & How Slab Intervals + Geometric Probability (SAH) Save It

算一笔账：一张 1080p 画面有 $2\times 10^6$ 个像素，每个像素连同反射、折射、阴影发射 $5$ 条射线，共 $10^7$ 条射线；如果电影级场景里有 $N = 10^7$ 个三角形，朴素的暴力循环（每条射线测试每一个三角形）一帧需要做 $10^{14}$（一百亿亿）次 Möller–Trumbore 求交！就算每秒算 10 亿次，渲染一帧也要整整 27 个小时！

怎么把 $O(N)$ 变成 $O(\log_2 N)$（$10^7$ 个三角形只需约 $24$ 次测试，提速40 万倍）？核心思想就像查字典一样：用容易求交的轴对齐包围盒 (AABB) 把成千上万个三角形层层包裹成一棵树——如果射线连外面的大盒子都没碰到，盒子里面的一百万个三角形看都不用看，直接整棵子树一刀剪除 (Pruning)！

Shooting $10^7$ rays against $N = 10^7$ triangles naively requires $10^{14}$ intersection tests per frame! By wrapping geometry in a hierarchy of Axis-Aligned Bounding Boxes (AABBs), if a ray misses a parent box, we prune all millions of triangles inside it in a single test — dropping complexity from $O(N)$ to $O(\log_2 N)$!

Kay–Kajiya AABB Slab 求交法 (1986)：把 3D 盒子看作 3 片无限平板的 CSG 交集！ The Kay–Kajiya AABB Slab Method (1986): A 3D Box Is the CSG Intersection of 3 Infinite Slabs!

一个轴对齐包围盒 (Axis-Aligned Bounding Box, AABB) 由三个坐标轴上的区间定义：$[x_{\min}, x_{\max}] \times [y_{\min}, y_{\max}] \times [z_{\min}, z_{\max}]$。 如果笨拙地把盒子当成 6 个矩形面分别求交，既啰嗦又慢。1986 年 Timothy Kay 与 James Kajiya 提出了天才的 Slab（平行板三明治）视角：
• 两张垂直于 $X$ 轴的无限平面 $x = x_{\min}$ 和 $x = x_{\max}$ 夹出了一片无限厚的X-方向平板 ($\text{Slab}_X$)；
• 三维盒子 $\text{AABB}$，本质上就是 $\text{Slab}_X \cap \text{Slab}_Y \cap \text{Slab}_Z$ 的 CSG 交集（Lesson 13）！

$$x(t) = o_x + t\,d_x = x_{\min} \implies t_{x,0} = \frac{x_{\min} - o_x}{d_x}, \qquad t_{x,1} = \frac{x_{\max} - o_x}{d_x}$$ $$\text{若 } d_x < 0 \text{ 则交换大小，得进入与离开 X 平板的时间: } [t_{x,\min},\; t_{x,\max}]$$

同理算出射线穿过 $Y$ 平板的时间区间 $[t_{y,\min}, t_{y,\max}]$ 和 $Z$ 平板的时间区间 $[t_{z,\min}, t_{z,\max}]$。 什么时候射线真正处在盒子内部？只有当射线已经进入了全部三个平板，且还没有离开任何一个平板时！因此对三个一维区间求交集 $[t_{\text{enter}}, t_{\text{exit}}]$：

$$t_{\text{enter}} = \max\!\big(t_{x,\min},\; t_{y,\min},\; t_{z,\min}\big), \qquad t_{\text{exit}} = \min\!\big(t_{x,\max},\; t_{y,\max},\; t_{z,\max}\big)$$ $$\text{射线命中 AABB} \iff \mathbf{t_{\text{enter}} \le t_{\text{exit}}} \;\;\text{且}\;\; \mathbf{t_{\text{exit}} > 0}$$

工业级加速技巧：在同一条射线遍历整棵 BVH 树时，预先算好倒数向量 $\text{invD} = (1/d_x, 1/d_y, 1/d_z)$，那么每个盒子的 Slab 测试完全没有除法，只剩 **6 次乘加 (FMA) 和 6 次 `min/max`**，GPU 硬件每时钟周期可并行测试数十个盒子！

① 积分几何 Crofton 定理：投影面积平均值 = 表面积的 $\frac{1}{4}$！ 1. Crofton's Theorem: Average Projected Area = $\frac{1}{4}$ Surface Area!

在构建 BVH 树时，怎么把一个父节点盒子 $B$ 切分成左子盒 $L$ 和右子盒 $R$ 才能让后续光线追踪最快？ 这取决于一个核心条件概率：已知一条随机方向的射线击中了父盒子 $B$，它接着击中内部子盒子 $A \subset B$ 的概率 $P(\text{hit } A \mid \text{hit } B)$ 是多少？

直觉可能会骗你说“看体积比 $\text{Vol}(A)/\text{Vol}(B)$”。但请想一想：一张极大却极薄的纸片，体积几乎为 $0$，却能挡住大量射线！ 对于任意固定方向 $\boldsymbol{\omega}$，平行射线束击中凸体 $A$ 的数量正比于 $A$ 在垂直于 $\boldsymbol{\omega}$ 平面上的正交投影面积 $A_\perp(\boldsymbol{\omega})$。而柯西-克罗夫顿（Cauchy–Crofton）定理证明：三维空间中任意凸体在所有方向上的平均投影面积，严格等于其总表面积 $S(A)$ 的四分之一！

$$\mathbb{E}_{\boldsymbol{\omega}}\!\big[A_\perp(\boldsymbol{\omega})\big] = \frac{1}{4}\,S(A) \implies P(\text{hit } A \mid \text{hit } B) = \frac{S(A)}{S(B)}$$

② 表面积启发式 (Surface Area Heuristic, SAH) 代价方程 2. The Surface Area Heuristic (SAH) Cost Equation

设测试一次包围盒的开销为 $C_{\text{trav}}$，测试一个三角形的开销为 $C_{\text{isect}}$。若将父盒子 $B$ 的 $N$ 个三角形划分为左子盒 $L$（含 $N_L$ 个三角形，表面积 $S(L)$）与右子盒 $R$（含 $N_R$ 个三角形，表面积 $S(R)$），则访问该节点的期望计算代价为：

$$C_{\text{SAH}}(L, R) = C_{\text{trav}} + \frac{S(L)}{S(B)}\,N_L\,C_{\text{isect}} + \frac{S(R)}{S(B)}\,N_R\,C_{\text{isect}}$$

为什么 SAH 完胜“空间中点切分 (Midpoint)”和“数量均分 (Equal-Count Median)”？ 假设左侧角落挤了 10 个极小的三角形，右侧散落着 2 个大三角形，中间有大片空白：
• 数量均分 (Median) 会强行把左侧密集簇劈成两半（左右两个盒子都很大且重叠）；
• SAH 则会贴着左侧密集簇边缘切一刀：左子盒虽然装着 $N_L=10$ 个三角形，但因为它的**表面积占比 $S(L)/S(B)$ 极小**，绝大多数射线根本不会碰它；而大片空白区域被瞬间隔离！

bool intersectAABB(vec3 orig, vec3 invDir, vec3 bMin, vec3 bMax,
                   float bestT, out float tEnter) {
  vec3 t0 = (bMin - orig) * invDir;
  vec3 t1 = (bMax - orig) * invDir;
  vec3 tmin = min(t0, t1), tmax = max(t0, t1);
  tEnter = max(max(tmin.x, tmin.y), tmin.z);
  float tExit = min(min(tmax.x, tmax.y), tmax.z);
  return (tEnter <= tExit) && (tExit > 0.0) && (tEnter < bestT);
}
