① 什么是“线性变换”？两条几何铁律 ① What Makes a Transformation "Linear"?

把线性变换想象成对整个三维空间的揉捏变形，但它必须遵守两条铁律：
1. 直线变形后依然是直线（且原本平行的网格线依然保持平行、等距分布）；
2. 坐标原点 (0,0,0) 必须被钉死在原地不动。
因为网格依然平行且等距，原本等于 x·î + y·ĵ + z·k̂ 的向量 v，在空间变形后，必然等于变形后的新基向量按完全相同的倍数 (x, y, z) 拼接而成：

A transformation L is linear if and only if:
1. Grid lines remain parallel and evenly spaced (lines stay lines);
2. The origin (0,0,0) remains fixed in place.
Because grid lines stay parallel and evenly spaced, a vector v = x·î + y·ĵ + z·k̂ transforms into the exact same linear recipe applied to the transformed basis vectors:

L(v) = x · L(î) + y · L(ĵ) + z · L(k̂)
② 为什么矩阵乘向量要那样算？ ② Why Is Matrix-Vector Multiplication Defined That Way?

设三个基向量变换后的新落点分别是列向量 u = L(î)、v = L(ĵ)、w = L(k̂)。把这三根新基向量肩并肩排成一个 3×3 表格（矩阵 M = [u | v | w]）：

Let u = L(î), v = L(ĵ), w = L(k̂) be the new coordinates where the basis vectors land. Packing them side-by-side as columns of M = [u | v | w] gives:

[u | v | w] · [x, y, z]ᵀ = x·u + y·v + z·w

瞬间顿悟：你根本不需要死背旋转、缩放、切变矩阵公式！想知道任何变换的矩阵，只需要问自己：“î, ĵ, k̂ 这三根针变换后落在了哪里？”把它们的落点竖着写进第 1、2、3 列，矩阵就写完了！

Aha Moment: Never memorize transformation matrices again! Just ask: "Where do î, ĵ, k̂ land?" and write their landing coordinates as Columns 1, 2, and 3!

③ 矩阵乘法 AB 与行列式 det(M) 的真相 ③ Matrix Product AB & Determinant det(M)

• 矩阵相乘 A·B：代表“先对空间施加变换 B，再施加变换 A”（像函数嵌套 A(B(x)) 一样从右往左读）。先旋转再沿 X 拉伸，与先沿 X 拉伸再旋转，基向量最终落点截然不同，所以 AB ≠ BA！
• 行列式 det(M)：代表单位立方体（体积=1）经过变形后体积被放大的倍率！若 det(M) < 0 说明空间发生了镜像翻转（右手系变左手系）；若 det(M) = 0 说明空间被压扁降维，不可逆！

• Matrix Product A·B: Apply transformation B first, then A (read right-to-left like A(B(x))). Order matters: AB ≠ BA!
• Determinant det(M): How much a unit cube's volume scales after transformation. det(M) < 0 means space flipped orientation; det(M) = 0 means space squished into lower dimensions!

第 1 步：为什么 3×3 矩阵绝对做不到 3D 平移？ Step 1: Why Can NO 3×3 Matrix Translate 3D Space?

因为任何 3×3 矩阵乘零向量永远等于零向量：M · [0, 0, 0]ᵀ = [0, 0, 0]ᵀ！线性变换的原点被死死钉在 (0,0,0)，而平移要求把原点搬到 (tₓ, tᵧ, t_z)。如果不能把平移也塞进矩阵乘法，骨骼层级变换就会退化成一团乱麻的加法嵌套。

Because for ANY 3×3 matrix M, M · [0, 0, 0]ᵀ = [0, 0, 0]ᵀ! Linear transformations lock the origin in place, whereas translation moves (0,0,0) to (tₓ, tᵧ, t_z).

为什么网格变形时，表面法向量 N 不能乘 M，而必须乘逆转置矩阵 (M⁻¹)ᵀ？ Why Must Surface Normals Transform by the Inverse-Transpose Matrix (M⁻¹)ᵀ Instead of M?

① 切向量 (Tangent) 与法向量 (Normal) 的根本几何区别 ① Tangent Vectors vs. Normal Vectors

• 表面切向量 t = P₂ - P₁ 是连接表面两个顶点的位移向量。当顶点乘矩阵 M 变形时，切向量确实跟着乘 M：t' = M·t。
• 但法向量 n 不是表面上的线段，它的唯一职责是“与表面切向量保持 90° 垂直（点积为 0）”！
• 请看右侧画布：当你把圆在 X 方向拉宽 2 倍（sₓ = 2, sᵧ = 1）时，斜率为 -1 的切线变得更平缓了；如果把法线 n 也傻傻地乘以 M（X 分量也拉长 2 倍，见红色箭头 M·n），法线反而更往水平方向倒，跟表面完全不垂直了！要继续垂直于变平缓的表面，法线的 X 分量反而必须缩小为 1/2！

• Tangent vectors t = P₂ - P₁ connect two surface points, so they transform directly by M: t' = M·t.
• Normal vectors n are defined by an orthogonality constraint: "stay perpendicular to tangents (dot product = 0)"!
• Look at the right canvas: stretching X by 2× flattens the surface slope; multiplying the normal by M (red arrow M·n) tilts it horizontally too, breaking perpendicularity!

② 三行代数推导：从点积守恒 nᵀ·t = 0 推导出 (M⁻¹)ᵀ ② 3-Line Proof: Preserving Orthogonality nᵀ·t = 0

把点积写成矩阵乘法 n · t = nᵀ t = 0。在中间插入单位矩阵 I = M⁻¹ M：

Write the dot product as n · t = nᵀ t = 0 and insert the identity matrix I = M⁻¹ M:

0 = nᵀ · t = nᵀ · (M⁻¹ · M) · t
0 = (nᵀ · M⁻¹) · (M · t) = ((M⁻¹)ᵀ · n)ᵀ · t'
⇒ n' = (M⁻¹)ᵀ · n (GLSL: mat3(transpose(inverse(uModel))))

工程推论：如果 M 只是纯旋转矩阵 R，因为正交矩阵满足 R⁻¹ = Rᵀ，此时 (R⁻¹)ᵀ = (Rᵀ)ᵀ = R，可以直接乘 R；但只要含非均匀缩放或切变，就必须乘 (M⁻¹)ᵀ！

Takeaway: For pure rotations R⁻¹ = Rᵀ so (R⁻¹)ᵀ = R. Whenever non-uniform scaling or shear is present, you MUST use (M⁻¹)ᵀ!
