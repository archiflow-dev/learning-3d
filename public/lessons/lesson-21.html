L21: 光照与着色模型：从 Flat/Gouraud/Phong 到现代微表面 PBR (Cook–Torrance)

💡 Gouraud (1971) • Phong (1975) • Jim Blinn (1977) • Cook–Torrance (1982)

1. 别把“着色频率”和“反射模型”混为一谈！为什么 Gouraud 着色会把高光彻底吞掉？

初学者常问：“Phong 着色和 Phong 光照模型有什么区别？”它们属于两个完全正交的维度： 着色频率 (Shading Frequency) 决定“在什么粒度上执行光照方程”（每三角形、每顶点、还是每像素）；而 反射模型 (BRDF) 决定“光照方程本身怎么写”！

  • Flat Shading（逐面片着色，1 次/三角形）：整个三角形共用唯一一个面法线 $\mathbf{N}_f = \text{normalize}((V_1-V_0)\times(V_2-V_0))$，画面像棱角分明的水晶切面。
  • Gouraud Shading（逐顶点着色 + 颜色插值，3 次/三角形）：在三个顶点 $V_0, V_1, V_2$ 处分别算出颜色 $C_0, C_1, C_2$，再用重心坐标在三角形内部线性插值颜色。
    致命缺陷：高光函数 $(\mathbf{N}\cdot\mathbf{H})^p$ 是高度非线性的尖峰！如果一束强光恰好打在大三角形的正中心（而三个顶点離高光中心都很远，算出来的顶点高光全为 $0$），那么无论怎么线性插值三个 $0$，三角形内部的高光都会彻底人间蒸发！
  • Phong Shading（逐顶点法线插值 + 逐像素着色）：不在顶点算颜色，而是用重心坐标把顶点法线插值到每一个像素，逐像素重新归一化 $\mathbf{N}(x,y) = \text{normalize}(\alpha\mathbf{N}_0 + \beta\mathbf{N}_1 + \gamma\mathbf{N}_2)$ 并计算光照——哪怕三角形再大，中心高光也圆润锐利！

2. 从半程向量 $\mathbf{H}$ 到微表面 PBR (Cook–Torrance)：为什么物理世界由 $D \cdot F \cdot G$ 统治？

3Blue1Brown 微观几何直觉：为什么半程向量 $\mathbf{H} = \frac{\mathbf{L} + \mathbf{V}}{\|\mathbf{L} + \mathbf{V}\|}$ 是整个现代 PBR 的基石？ 把任何粗糙物体（磨砂金属、塑料、皮肤）放在电子显微镜下放大一万倍，你会发现它的表面是由无数个朝向各异的**微小理想平面镜（Microfacets，微平面）**组成的崎岖山谷！

现在问一个纯粹的几何问题：在这些成千上万个微平面中，究竟哪些微平面能把来自方向 $\mathbf{L}$ 的入射光，恰好反射进方向 $\mathbf{V}$ 的相机眼睛里？ 根据反射定律（入射角等于反射角），只有那些微法线 $\mathbf{m}$ 恰好对准了 $\mathbf{L}$ 与 $\mathbf{V}$ 的角平分线——也就是半程向量 $\mathbf{H}$ 的微平面（即满足 $\mathbf{m} = \mathbf{H}$ 的“有效微镜面”），才能把光子反射进相机！

$$f_{\text{Cook-Torrance}}(\mathbf{l}, \mathbf{v}) = k_d \frac{\mathbf{c}_{\text{diff}}}{\pi} + \frac{\overbrace{D(\mathbf{h}, \alpha)}^{\text{朝向 }\mathbf{h}\text{ 的微镜面密度}} \cdot \overbrace{F(\mathbf{v}, \mathbf{h}, F_0)}^{\text{菲涅尔反射率}} \cdot \overbrace{G(\mathbf{l}, \mathbf{v}, \alpha)}^{\text{未被山峰挡住的比例}}}{4 (\mathbf{n} \cdot \mathbf{l}) (\mathbf{n} \cdot \mathbf{v})}$$
  1. $D(\mathbf{h}, \alpha)$ — GGX 微表面法线分布函数 (NDF)：统计有多大比例的微平面法线恰好朝向 $\mathbf{h}$： $$D_{\text{GGX}}(\mathbf{n}, \mathbf{h}, \alpha) = \frac{\alpha^2}{\pi \big((\mathbf{n}\cdot\mathbf{h})^2 (\alpha^2 - 1) + 1\big)^2}, \qquad (\alpha = \text{Roughness}^2)$$ 与违反能量守恒的传统 Blinn–Phong 不同，当粗糙度变大时，GGX 波瓣变宽的同时峰值高度自动按比例大幅降低，保证半球积分能量恒等于 $1$！
  2. $F(\mathbf{v}, \mathbf{h}, F_0)$ — Schlick 菲涅尔反射方程： $$F(\mathbf{v}, \mathbf{h}) = F_0 + (1 - F_0)\big(1 - (\mathbf{v}\cdot\mathbf{h})\big)^5$$ 金属 (Conductors) vs. 电介质 (Dielectrics)：非金属（塑料/水/玉石）垂直反射率极低（$F_0 \approx 0.04$ 无色灰白），折射进内部的光形成漫反射 $\mathbf{c}_{\text{diff}}$；而金属内部自由电子会瞬间吸收所有折射光（漫反射 $\mathbf{c}_{\text{diff}} \equiv \mathbf{0}$！），其全部颜色来自带色彩倾向的高反射率 $F_0$（如黄金 $F_0 = (1.0, 0.78, 0.34)$），但在掠射边缘（$\mathbf{v}\cdot\mathbf{h} \to 0$）无论是金属还是塑料都会趋向 $100\%$ 全反射白光！
  3. $G(\mathbf{l}, \mathbf{v}, \alpha)$ — Smith 几何遮蔽与掩蔽函数 (Shadowing-Masking)：在粗糙的微观山谷中，有些微平面虽然朝向 $\mathbf{h}$，但入射光 $\mathbf{l}$ 被左侧山峰挡住了（Shadowing 阴影），或者反射光 $\mathbf{v}$ 被右侧山峰拦住了（Masking 掩蔽）！$G \in [0, 1]$ 精确扣除了这部分死角，并压制分母 $4(\mathbf{n}\cdot\mathbf{l})(\mathbf{n}\cdot\mathbf{v})$ 在掠射角处的无穷大爆炸！

Shading Models, BRDF Energy Conservation & Cook–Torrance GLSL Implementation

▶ UC Davis Lecture 08 (Color and Shading) ↗ ▶ MIT 6.837 Lecture 13 (Shading) ↗
💻 工业级 Cook–Torrance GGX 微表面 PBR 核心着色器代码 (GLSL / HLSL)
// 1. Trowbridge-Reitz GGX 法线分布函数 D(n, h, α)
float DistributionGGX(vec3 N, vec3 H, float roughness) {
  float a  = roughness * roughness;
  float a2 = a * a;
  float NdotH  = max(dot(N, H), 0.0);
  float denom = (NdotH * NdotH * (a2 - 1.0) + 1.0);
  return a2 / (PI * denom * denom);
}

// 2. Schlick-GGX 几何遮蔽函数 G(n, v, l, k)
float GeometrySchlickGGX(float NdotV, float roughness) {
  float r = (roughness + 1.0);
  float k = (r * r) / 8.0; // 直接光照重映射
  return NdotV / (NdotV * (1.0 - k) + k);
}
float GeometrySmith(vec3 N, vec3 V, vec3 L, float roughness) {
  return GeometrySchlickGGX(max(dot(N, V), 0.0), roughness) *
         GeometrySchlickGGX(max(dot(N, L), 0.0), roughness);
}

// 3. Fresnel-Schlick 方程 F(v, h, F0)
vec3 fresnelSchlick(float cosTheta, vec3 F0) {
  return F0 + (1.0 - F0) * pow(clamp(1.0 - cosTheta, 0.0, 1.0), 5.0);
}

// 4. 组合 Cook-Torrance BRDF (严格能量守恒：kD = (1 - F) * (1 - metallic))
vec3 F0 = mix(vec3(0.04), albedo, metallic);
vec3 F  = fresnelSchlick(max(dot(H, V), 0.0), F0);
float D = DistributionGGX(N, H, roughness);
float G = GeometrySmith(N, V, L, roughness);
vec3 specular = (D * G * F) / max(4.0 * max(dot(N, V), 0.0) * max(dot(N, L), 0.0), 0.0001);
vec3 kD = (vec3(1.0) - F) * (1.0 - metallic);
vec3 Lo = (kD * albedo / PI + specular) * radiance * max(dot(N, L), 0.0);
