L16: 信号处理、采样理论与反走样 (Sampling, Nyquist & Antialiasing)

💡 Alvy Ray Smith (1995) & 3Blue1Brown 信号观

为什么“像素绝不是一个小方块”？(A Pixel is NOT a Little Square!)

初学者往往把屏幕上的像素看成一个个涂满均匀颜色的“小瓷砖”。但在皮克斯联合创始人 Alvy Ray Smith 的著名论文与 MIT 6.837 的信号处理框架中：三维场景投射到像平面上的辐射亮度 $I(x,y)$ 是一个**连续的二维光场信号**，而数字图像本质上是定义在规则晶格点 $(i, j)$ 上的**离散点采样 (Point Samples)**！当我们只从每个像素中心发射 1 条射线时，就是在拿一根无穷细的针去刺探连续世界——任何落在这根针旁边的亚像素细节（比如远处的高频棋盘格或斜边三角形边缘）都会触发灾难性的**频谱混叠 (Aliasing)**。

1. 空间锯齿 (Jaggies / Staircasing)

三角形的锋利边缘在数学上是一个阶跃函数 (Heaviside Step)，其傅里叶频谱以 $1/\omega$ 衰减并延伸至无穷大频率 ($\omega \to \infty$)。单点采样将连续斜边生硬截断为 $0$ 或 $1$ 的阶梯。

2. 摩尔纹伪影 (Moiré Patterns)

透视投影下的地面棋盘格在趋近地平线时，空间频率随深度 $z$ 线性暴涨 ($f \propto z \to \infty$)。高频条纹超越采样率的一半后，“折叠”伪装成原本根本不存在的巨大弧形低频条纹！

3. 时间闪烁与萤火虫 (Temporal Shimmering)

细电线或高光点宽度小于 1 个像素间距时，随相机微微移动，它一会儿碰巧撞上采样针（突然全亮），一会儿滑进两针缝隙（瞬间消失），造成画面剧烈闪烁。

1. 为什么高频信号会“伪装”成低频？——从车轮倒转到傅里叶频谱复制

先看最直观的**空域/时域现象**（电影里的马车轮倒转效应）：假设真实连续信号是余弦波 $s(x) = \cos(2\pi f x)$，我们以采样率 $f_s$（采样间隔 $\Delta x = 1/f_s$）在离散坐标 $x_n = n / f_s$ 处进行点采样。

$$\cos\!\left(2\pi (f + k f_s) \frac{n}{f_s}\right) = \cos\!\left(2\pi f \frac{n}{f_s} + \underbrace{2\pi k n}_{\text{整数圈 } 2\pi}\right) = \cos\!\left(2\pi f \frac{n}{f_s}\right)$$

因为余弦函数具有 $2\pi$ 周期性，加上 $f_s$ 的任意整数倍 $k \cdot f_s$ 后，在所有采样点 $x_n$ 上的读数**一模一样**！这意味着：一旦真实频率 $f$ 超过了采样率的一半（**奈奎斯特极限 $f_{\text{Nyquist}} = f_s / 2$**），离散采样点就彻底分不清它是高频波 $f$，还是折叠回基带 $[-f_s/2, +f_s/2]$ 内的低频“冒名顶替者 (Alias)”：

$$f_{\text{alias}} = \big|\, f - \text{round}(f / f_s) \cdot f_s \,\big| \le \frac{f_s}{2}$$

再看 **3Blue1Brown 式的频域对偶证明**：在空域中对信号做等间距点采样，等价于将连续信号 $s(x)$ 乘以狄拉克梳状函数 (Dirac Comb) $\text{III}_{\Delta x}(x) = \sum_{n=-\infty}^{\infty} \delta(x - n\Delta x)$。根据**傅里叶卷积定理：空域相乘 $\iff$ 频域卷积**！

$$s_{\text{sampled}}(x) = s(x) \cdot \text{III}_{\Delta x}(x) \;\;\xrightarrow{\mathcal{F}}\;\; S_{\text{sampled}}(\omega) = f_s \sum_{k=-\infty}^{\infty} S(\omega - k f_s)$$

换句话说：**采样操作会在频率轴上每隔 $f_s$ 就无限克隆（复制）一份原始频谱 $S(\omega)$**！只有当采样率满足**奈奎斯特–香农采样定理 $f_s \ge 2 f_{\max}$** 时，相邻克隆频谱才不会互相踩踏重叠；反之，高频尾巴侵入基带 $[-f_s/2, +f_s/2]$，就会永久污染低频信号！

2. 既然三角形边缘带宽无穷大 ($f_{\max} = \infty$)，我们该如何反走样？

在光栅化或光线追踪中，解析地把三维场景先做理想低通滤波（Pre-filtering）往往极其困难，所以我们采用**三大武器**协同作战：

  1. 超采样 (Supersampling, 提高 $f_s$)：在每个像素内部密集发射 $N = M \times M$ 条子采样射线，将奈奎斯特极限 $f_s / 2$ 推向更高频率，然后用重建滤波器将子样本加权合成为最终像素值：
    $$I_{\text{pixel}}(i, j) = \frac{\sum_{k=1}^{N} w_k \, I(x_k, y_k)}{\sum_{k=1}^{N} w_k}, \qquad w_k = h\!\left(x_k - i,\; y_k - j\right)$$
  2. 分层抖动采样 (Stratified Jittered Sampling, 将混叠转化为蓝噪点)：如果使用死板的规则网格采样 ($M \times M$ Regular Grid)，遇到高频棋盘格依然会产生规则的摩尔纹。我们将像素划分为 $M \times M$ 个互不重叠的小格子 (Strata)，在每个小格子 $(p, q)$ 内部随机抖动采样点：
    $$u_{p,q} = \frac{p + \xi_x}{M}, \quad v_{p,q} = \frac{q + \xi_y}{M}, \qquad \xi_x, \xi_y \sim \mathcal{U}[0, 1)$$
    这既打破了周期晶格（把讨厌的整片摩尔纹打散为人眼极易忽略的无害高频噪点），又避免了纯随机采样 (Uniform Random) 的样本扎堆与空白漏检！
  3. 精心设计的重建滤波核 $h(r)$ (Box vs. Tent vs. Gaussian vs. Sinc)： 不同滤波核在空域与频域之间做着经典的权衡—— Box 盒式滤波（像素内等权重平均）在频域是 $\text{sinc}(\omega)$，旁瓣极高，会漏入大量高频混叠； Tent 帐篷滤波（线性衰减）在频域是 $\text{sinc}^2(\omega)$，旁瓣大幅压低； Gaussian 高斯滤波在空域与频域都是平滑高斯钟形曲线，既无高频旁瓣泄漏，也无负权重引起的吉布斯振铃 (Ringing)！

⚡ 为什么 GPU 偏爱 MSAA 而非 SSAA？(解耦覆盖测试与着色计算)

在现代实时渲染管线中，一个像素的 **Fragment Shader（片元着色器）** 往往需要查询多张法线/PBR 贴图并计算复杂光照，开销极其高昂；但大多数高频锯齿其实只发生在**三角形的几何轮廓边缘 (Silhouette Edges)**，而不是三角形内部平滑渐变的表面！

  • SSAA (Supersampling AA)：简单粗暴地把帧缓冲分辨率放大 $4\times$ 或 $16\times$，对每个子样本都完整执行一次几何覆盖测试 + 一次昂贵的 Fragment Shader。算力与显存带宽直接暴涨 $4\sim 16$ 倍。
  • MSAA (Multisample AA)：在每个像素内放置 $4$ 或 $8$ 个子采样点（通常采用 **4x RGSS 旋转网格** 或 **8x 皇后分布 N-Rooks**），对每个子采样点测试**三角形覆盖率 (Coverage) 与深度值 (Z-Buffer)**；但对于覆盖该像素的同一个三角形，**Fragment Shader 只在像素中心（或覆盖重心 Centroid）执行唯一 1 次**，再把算出的颜色广播写入所有通过深度测试的子样本中！

// 1. 生成 M×M 分层抖动采样点 (Stratified Jittered Samples in [-0.5, +0.5]^2)
function renderPixelStratified(px: number, py: number, M: number, filterRadius: number): RGB {
  let weightSum = 0.0;
  let colorAccum = new RGB(0, 0, 0);
  const sigma = filterRadius * 0.5;
  const alpha = 1.0 / (2.0 * sigma * sigma);
  const baseExp = Math.exp(-alpha * filterRadius * filterRadius);

  for (let sy = 0; sy < M; sy++) {
    for (let sx = 0; sx < M; sx++) {
      // 在第 (sx, sy) 个子格内部均匀随机抖动 ξ_x, ξ_y ∈ [0, 1)
      const dx = ((sx + Math.random()) / M - 0.5) * (2.0 * filterRadius);
      const dy = ((sy + Math.random()) / M - 0.5) * (2.0 * filterRadius);
      const r2 = dx * dx + dy * dy;
      if (r2 >= filterRadius * filterRadius) continue;

      // 2. 截断高斯重建滤波核 h(r) = max(0, exp(-α r²) - exp(-α R²))
      const w = Math.max(0.0, Math.exp(-alpha * r2) - baseExp);
      const sampleColor = traceRay(px + 0.5 + dx, py + 0.5 + dy);
      colorAccum = colorAccum.add(sampleColor.scale(w));
      weightSum += w;
    }
  }
  return colorAccum.scale(1.0 / Math.max(weightSum, 1e-6));
}
