重心坐标 $(\alpha, \beta, \gamma)$：对门子三角形面积比与阿基米德天平 Barycentric Coordinates $(\alpha, \beta, \gamma)$: Opposite Sub-Triangle Area Ratios & Archimedes' Lever

① 仿射组合视角：把三角形变成斜坐标系 1. Affine Combination: The Triangle as an Oblique Basis

给定三角形的三个顶点 $\mathbf{a}, \mathbf{b}, \mathbf{c}$，平面内的任意一点 $\mathbf{p}$ 都可以唯一地写成三个顶点的仿射加权平均：

$$\mathbf{p}(\alpha, \beta, \gamma) = \alpha\mathbf{a} + \beta\mathbf{b} + \gamma\mathbf{c}, \qquad \alpha + \beta + \gamma = 1$$ $$\text{代入 } \alpha = 1 - \beta - \gamma \implies \mathbf{p} - \mathbf{a} = \beta(\mathbf{b} - \mathbf{a}) + \gamma(\mathbf{c} - \mathbf{a})$$

看第二个式子！这不就是以 $\mathbf{a}$ 为原点，以两条边向量 $\mathbf{e}_1 = \mathbf{b} - \mathbf{a}$ 和 $\mathbf{e}_2 = \mathbf{c} - \mathbf{a}$ 为基向量的二维斜坐标系吗？！
• 三角形内外部充要条件：点 $\mathbf{p}$ 落在 $\triangle abc$ 内部（含边界）$\iff$ $\alpha \ge 0,\; \beta \ge 0,\; \gamma \ge 0$！只要有一个坐标小于 $0$，点就跑出了那条对边之外！
• 万用属性插值器：一旦算出 $(\alpha, \beta, \gamma)$，无论是顶点颜色 $(R,G,B)$、纹理坐标 $(u,v)$、深度还是 Phong 法向量，全都用同一个公式丝滑插值： $$\Phi(\mathbf{p}) = \alpha\,\Phi_a + \beta\,\Phi_b + \gamma\,\Phi_c$$

② 为什么要叫“重心”坐标？对门子三角形有向面积比推导！ 2. Why "Barycentric"? The Opposite Signed-Area Ratio Proof!

把内部点 $\mathbf{p}$ 与三个顶点 $\mathbf{a}, \mathbf{b}, \mathbf{c}$ 连起来，大三角形 $\triangle abc$ 被切成了三块子三角形（注意：顶点 $\mathbf{a}$ 的权重 $\alpha$ 对应的是它对面的子三角形 $\triangle pbc$！）。 为什么 $\beta = \frac{\text{Area}(\triangle apc)}{\text{Area}(\triangle abc)}$？用 Lesson 01 的叉积面积公式一步秒杀： 将 $\mathbf{p} - \mathbf{a} = \beta(\mathbf{b}-\mathbf{a}) + \gamma(\mathbf{c}-\mathbf{a})$ 与边向量 $(\mathbf{c}-\mathbf{a})$ 做叉积（因为 $(\mathbf{c}-\mathbf{a})\times(\mathbf{c}-\mathbf{a}) = \mathbf{0}$ 自动消去 $\gamma$！）：

$$(\mathbf{p} - \mathbf{a}) \times (\mathbf{c} - \mathbf{a}) = \beta\,(\mathbf{b} - \mathbf{a}) \times (\mathbf{c} - \mathbf{a})$$ $$\implies \alpha = \frac{A_a}{A} = \frac{[(\mathbf{b}-\mathbf{p})\times(\mathbf{c}-\mathbf{p})]\cdot\hat{\mathbf{n}}}{[(\mathbf{b}-\mathbf{a})\times(\mathbf{c}-\mathbf{a})]\cdot\hat{\mathbf{n}}}, \quad \beta = \frac{A_b}{A}, \quad \gamma = \frac{A_c}{A}$$

物理直觉（阿基米德重心）：如果在三个顶点分别挂上质量为 $\alpha, \beta, \gamma$ 的秤砣，整块三角形铁板的物理平衡支点（重心 Center of Mass）就恰好停在点 $\mathbf{p}$！点 $\mathbf{p}$ 越靠近顶点 $\mathbf{a}$，对面的子三角形面积 $A_a$ 就占满整块面积 $A$，$\alpha \to 1$！

Möller–Trumbore 快速三角形求交 (1997)：克拉默法则与平行六面体体积比 Möller–Trumbore Fast Ray-Triangle Intersection: Cramer's Rule & Parallelepiped Volumes

笨办法求射线与三角形交点需要两步：先求射线与三角形所在无限平面的交点 $t$，再算三维面积比判断交点是否在三角形内。1997 年 Tomas Möller 与 Ben Trumbore 发现：直接让射线方程 $\mathbf{o} + t\mathbf{d}$ 等于三角形重心方程 $\mathbf{a} + \beta(\mathbf{b}-\mathbf{a}) + \gamma(\mathbf{c}-\mathbf{a})$，就能一步同时解出 $(t, \beta, \gamma)$！

1. 线性方程组构造：记 $\mathbf{e}_1 = \mathbf{b} - \mathbf{a}$，$\mathbf{e}_2 = \mathbf{c} - \mathbf{a}$，右端项 $\mathbf{s} = \mathbf{o} - \mathbf{a}$ 1. The $3\times 3$ Linear System: Let $\mathbf{e}_1 = \mathbf{b} - \mathbf{a}$, $\mathbf{e}_2 = \mathbf{c} - \mathbf{a}$, $\mathbf{s} = \mathbf{o} - \mathbf{a}$
$$\mathbf{o} + t\mathbf{d} = \mathbf{a} + \beta\mathbf{e}_1 + \gamma\mathbf{e}_2 \iff \begin{bmatrix} -\mathbf{d} & \mathbf{e}_1 & \mathbf{e}_2 \end{bmatrix} \begin{bmatrix} t \\ \beta \\ \gamma \end{bmatrix} = \mathbf{s}$$
2. 3Blue1Brown 克拉默法则（体积比！）与标量三重积 $\det[\mathbf{u},\mathbf{v},\mathbf{w}] = (\mathbf{u}\times\mathbf{v})\cdot\mathbf{w}$ 2. 3Blue1Brown Cramer's Rule (Volume Ratios!) & Scalar Triple Products

在 3Blue1Brown《线性代数的本质》第 6 集中，三阶行列式 $\det[-\mathbf{d}, \mathbf{e}_1, \mathbf{e}_2]$ 就是由 $-\mathbf{d}, \mathbf{e}_1, \mathbf{e}_2$ 张成的三维平行六面体有向体积！利用循环轮换恒等式 $\det[\mathbf{u},\mathbf{v},\mathbf{w}] = (\mathbf{u}\times\mathbf{w})\cdot\mathbf{v} = (\mathbf{v}\times\mathbf{w})\cdot\mathbf{u}$，记两个可复用的叉积向量 $\mathbf{p} = \mathbf{d} \times \mathbf{e}_2$ 与 $\mathbf{q} = \mathbf{s} \times \mathbf{e}_1$：

$$\begin{bmatrix} t \\ \beta \\ \gamma \end{bmatrix} = \frac{1}{\det[-\mathbf{d}, \mathbf{e}_1, \mathbf{e}_2]} \begin{bmatrix} \det[\mathbf{s}, \mathbf{e}_1, \mathbf{e}_2] \\ \det[-\mathbf{d}, \mathbf{s}, \mathbf{e}_2] \\ \det[-\mathbf{d}, \mathbf{e}_1, \mathbf{s}] \end{bmatrix} = \frac{1}{\mathbf{p}\cdot\mathbf{e}_1} \begin{bmatrix} \mathbf{q}\cdot\mathbf{e}_2 \\ \mathbf{p}\cdot\mathbf{s} \\ \mathbf{q}\cdot\mathbf{d} \end{bmatrix}$$

为什么全球所有的 GPU 光追硬件（NVIDIA RTX）都用这个公式？因为总共只需要 1 次除法、2 次叉积（$\mathbf{p}, \mathbf{q}$）和 4 次点积！而且无需预先存储三角形的平面方程，一旦算出 $\beta < 0$ 或 $\beta > 1$ 可以立即提前终止 (Early Exit)！

为什么非均匀缩放会让法向量“歪掉”？对偶逆转置矩阵 $(M^{-1})^\top$ 与 CSG 射线布尔代数 Why Non-Uniform Scaling Breaks Normals: The Inverse-Transpose $(M^{-1})^\top$ Proof & CSG Ray Intervals

① 法向量逆转置定理 $\mathbf{n}' = (M^{-1})^\top \mathbf{n}$ 的三行代数证明 1. The 3-Line Proof of Normal Matrix $\mathbf{n}' = (M^{-1})^\top \mathbf{n}$

假设你把一个单位圆球沿着 $X$ 轴拉长 $2$ 倍、沿着 $Y$ 轴压扁 $0.5$ 倍（线性变换矩阵 $M = \text{diag}(2, 0.5, 1)$）。表面上的切向量 $\mathbf{t}$ 是两个表面点的差 $\mathbf{p}_2 - \mathbf{p}_1$，因此切向量必然跟着乘以 $M$：$\mathbf{t}' = M\mathbf{t}$。
但如果你把法向量 $\mathbf{n}$ 也直接乘以 $M$（变成 $M\mathbf{n}$），它也会被横向拉平，不再垂直于压扁后的表面！
为什么？因为法向量 $\mathbf{n}$ 的唯一使命是与切向量保持正交（点积为 $0$：$\mathbf{n}^\top \mathbf{t} = 0$）！我们在中间插入一个单位矩阵 $I = M^{-1} M$：

$$0 = \mathbf{n}^\top \mathbf{t} = \mathbf{n}^\top \underbrace{(M^{-1} M)}_{I} \mathbf{t} = \big(\mathbf{n}^\top M^{-1}\big)\,(M\mathbf{t}) = \Big(\underbrace{(M^{-1})^\top \mathbf{n}}_{\mathbf{n}'}\Big)^\top \mathbf{t}' = 0$$

结论：只要令新法向量 $\mathbf{n}' = (M^{-1})^\top \mathbf{n}$，无论矩阵 $M$ 把物体怎么剪切或非均匀压扁，新法向量 $\mathbf{n}'$ 与新切向量 $\mathbf{t}' = M\mathbf{t}$ 的点积永远严格等于 $0$！（特例：当 $M = R$ 是纯旋转正交矩阵时，$R^{-1} = R^\top \implies (R^{-1})^\top = R$，所以纯旋转时法线可以直接乘 $R$！）

② 构造实体几何 (CSG)：把 3D 布尔运算降维成 1D 射线区间运算！ 2. Constructive Solid Geometry (CSG): 3D Booleans as 1D Ray Intervals!

怎么在光线追踪里渲染一个“球体 $A$ 挖掉圆柱 $B$”的机械零件，或者两块透镜的交集 $A \cap B$？如果直接去算三维曲面网格的布尔切割，代码复杂到令人发指。
但在光线投射里，一条射线 $\mathbf{r}(t)$ 穿过封闭实体 $A$ 时，只是一段一维时间区间 $I_A = [t_{A,\text{in}}, t_{A,\text{out}}]$，穿过实体 $B$ 是区间 $I_B = [t_{B,\text{in}}, t_{B,\text{out}}]$！于是 3D 实体布尔运算瞬间简化为一维线段集合运算：

• 并集 (Union $A \cup B$)：$I_A \cup I_B = [\min(t_{A,\text{in}}, t_{B,\text{in}}),\; \max(t_{A,\text{out}}, t_{B,\text{out}})]$
• 交集 (Intersection $A \cap B$)：$I_A \cap I_B = [\max(t_{A,\text{in}}, t_{B,\text{in}}),\; \min(t_{A,\text{out}}, t_{B,\text{out}})]$
• 差集 (Difference $A \setminus B$)：从 $I_A$ 中挖掉 $I_B$！核心细节：当射线从被挖掉的 $B$ 退出来进入 $A$ 时（$t = t_{B,\text{out}}$），凹坑表面的法向量必须取反 $-\mathbf{n}_B$！

💻 工业级 Möller–Trumbore 三角形求交 GLSL / C++ 核心代码 💻 Production Möller–Trumbore Ray-Triangle Kernel 

bool intersectTriangleMT(vec3 o, vec3 d, vec3 a, vec3 b, vec3 c,
                         out float t, out float beta, out float gamma) {
  vec3 e1 = b - a;
  vec3 e2 = c - a;
  vec3 p  = cross(d, e2);         // p = d × e2
  float det = dot(p, e1);         // det = (d × e2) · e1
  if (abs(det) < 1e-7) return false; // Ray parallel to triangle plane

  float invDet = 1.0 / det;
  vec3 s = o - a;
  beta = dot(p, s) * invDet;      // Cramer's Rule for β
  if (beta < 0.0 || beta > 1.0) return false; // Early exit!

  vec3 q = cross(s, e1);          // q = s × e1
  gamma = dot(q, d) * invDet;     // Cramer's Rule for γ
  if (gamma < 0.0 || beta + gamma > 1.0) return false;

  t = dot(q, e2) * invDet;        // Cramer's Rule for t
  return t > 1e-5;                // alpha = 1 - beta - gamma
}
