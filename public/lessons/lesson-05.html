Part 1 • 3Blue1Brown 矩阵级联对偶直觉

为什么矩阵链 p_world = M₁ · M₂ · M₃ · p_local 既能“从右往左读”，又能“从左往右读”？

M_world = M_parent · M_local
🧭 读法 A：从左往右读（随身携带局部标架 / Moving Local Frame）

把每一次**右乘**新矩阵，看作**“在当前局部标架内部，进一步移动或旋转坐标网格本身”**：

F₀ (World) --[右乘 M₁]--> F₁ (Shoulder) --[右乘 M₂]--> F₂ (Elbow) --[右乘 M₃]--> F₃ (Claw)

**为什么在局部标架下追加变换是“右乘” $M_1 M_2$？** 因为 $M_1$ 的列向量就是父标架 $\mathcal{F}_1$ 的基向量。子标架 $\mathcal{F}_2$ 在父标架 $\mathcal{F}_1$ 眼里的坐标是 $M_2$，要把 $\mathcal{F}_1$ 里的坐标翻译成世界坐标，必须用 $M_1$ 左乘它——结果正是 $M_{\text{world}} = M_1 M_2$！

🌍 读法 B：从右往左读（固定世界原点 / Fixed World Frame）

把括号套在向量 $\mathbf{p}$ 上：$\mathbf{p}_{\text{world}} = M_1 \big( M_2 ( M_3 \mathbf{p}_{\text{local}} ) \big)$。每一次左乘都是在**固定不变的世界原点 $(0,0)$** 进行操作：

p_local --[在世界原点执行 M₃]--> p' --[在世界原点执行 M₂]--> p'' --[在世界原点执行 M₁]--> p_world

先在世界原点把机械爪转好 ($M_3$)，再在世界原点把它往外推前臂长度 $L_2$ 并旋转手肘角 ($M_2$)，最后把整套组合往外推大臂长度 $L_1$ 并旋转肩膀角 ($M_1$)。**两条路径最终严格汇聚于同一点！**

为什么分叉场景图 (Scene Graph) 必须使用矩阵栈 (`pushMatrix` / `popMatrix`)？

DFS Traversal + LIFO Stack
1. 分叉兄弟节点的“矩阵污染”难题

手腕节点 (`Wrist`) 下有两个并列的子节点：**左手指 (`Left Finger`)** 和 **右手指 (`Right Finger`)**。当你算完 `CTM = CTM * M_left` 画完左手指后，`CTM` 已经跑到左手指尖了！如果不回退到 `Wrist` 的矩阵就直接乘 `M_right`，**右手指就会从左手指尖长出来**！

2. `pushMatrix()`：压栈备份父标架

在深度优先遍历 (DFS) 进入任何子节点前，先调用 `pushMatrix()` 把当前栈顶矩阵复制一份压入栈顶；随后放心地右乘子节点的局部矩阵：`CTM = CTM * M_local` 并绘制几何体。

3. `popMatrix()`：出栈无损回滚

当该子节点及其子树全部绘制完毕后，调用 `popMatrix()` 弹出栈顶！被污染的矩阵瞬间销毁，`CTM` 完美恢复成干净的父节点标架，继续处理下一个兄弟分支！

Prof. Kenneth Joy — The Hierarchical Modeling System

📌 Kenneth Joy 教授的“局部枢轴原点建模黄金法则”：

在构建机械臂、钟摆或人体骨骼的每一个零件时，永远把该零件的旋转铰链（Pivot / Joint）放在它自己局部坐标系的原点 $(0,0,0)$！

// OpenGL / Matrix Stack Standard DFS Pattern:
function traverseNode(node) {
  pushMatrix(); // Save parent CTM
  multMatrix(node.M_local); // CTM = CTM * T(joint_offset) * R(theta)
  drawCanonicalMesh(node.mesh);
  for (child of node.children) traverseNode(child);
  popMatrix(); // Restore parent CTM for siblings!
}

这样做有什么巨大好处？从父关节跳到子关节永远只需要两步：① 沿着父骨骼长度平移 $T(0, L_{\text{parent}}, 0)$；② 绕子关节原点直接旋转 $R(\theta_{\text{child}})$！再也不需要繁琐的 $T(\mathbf{p}) R(\theta) T(-\mathbf{p})$ 三步绕点旋转！
